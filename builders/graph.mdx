## What this page covers

- Graph data model
- What lives in the graph (and what doesn't)
- Privacy and access scoping
- Read and write semantics
- Query patterns

## Outline

### Data model
Nodes (Members, Allies, Kidunas, Alliances, Offerings, proposals, ...). Edges (relationships, attributions, governance links). Properties.

### What lives where
Graph-stored, on-chain, off-chain, in private institutional records — which is which.

### Privacy and scoping
How Members' data is protected. How access is granted and revoked. Group-level scoping.

### Read semantics
How an agent or service queries the graph.

### Write semantics
What can write to the graph and how writes are authorized.

### Query patterns
Common patterns: tracing provenance, finding Alliances, surfacing Members aligned with a Mission.
