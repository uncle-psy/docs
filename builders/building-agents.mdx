## What this page covers

- The build process per agent type
- Code-bearing patterns (how an agent presents a Kiduna Code)
- Scope discipline
- Testing and dry-run patterns
- Publishing to Kiduna Exchange

## Outline

### Build process per type
What you start from, what you need to specify, what the system provides.

### Code-bearing patterns
How an agent presents its Code, how it negotiates scope with counterparties.

### Scope discipline
Principle of least authority. How to design scope that's tight enough to be safe and broad enough to be useful.

### Testing
Local test patterns, dry-runs against a sandboxed Kiduna.

### Publishing
How to list an agent on Kiduna Exchange. Provenance, attribution, pricing.
